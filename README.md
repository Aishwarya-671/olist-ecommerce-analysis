# Olist E-commerce Analytics & Data Quality Audit

An end-to-end analysis of ~100,000 real orders from Olist, a Brazilian e-commerce marketplace.
The project audits the data's quality, answers 20+ business questions with SQL, and publishes the findings.

## Status

In progress

## Tools

- DuckDB
- SQL
- Git and GitHub

The raw data is not stored in this repo.
